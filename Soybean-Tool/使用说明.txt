==================================================
    大豆图像处理工具 - 使用说明
==================================================

【目录结构】
Soybean-Tool/
├─ batch_process.exe     ← 主程序
├─ images/               ← 输入图片目录
│  ├─ bg/               ← 放置背景图（植株）
│  ├─ pod/              ← 放置豆荚图
│  └─ seed/             ← 放置种子图
└─ 使用说明.txt          ← 本文件


【第一步：准备图片】
1. 将三类图片分别放入对应文件夹
2. **重要**：同一组图片的文件名中要包含相同的4位数字编号
   
   示例：
   images/bg/   GY2025HHN-0001.jpg
   images/pod/  GY2025-0001.jpg  
   images/seed/ GY-0001.jpg
   
   ↑ 这三张图会被识别为同一组（编号：0001）


【第二步：运行程序】
1. 双击 batch_process.exe
2. 程序会扫描图片并显示找到多少组
3. 按提示输入从第几组开始（默认输入 1）


【第三步：操作流程】
程序会依次处理每一组图片，每组包含以下步骤：

┌─────────────────────────────────────┐
│ 步骤1：清理背景                      │
├─────────────────────────────────────┤
│ • 用鼠标拖拽框选要删除的物体         │
│   （如标尺、白色标牌等）             │
│ • 可以框选多个区域                   │
│ • 按 SPACE 键开始修复                │
│ • 修复完成后可继续框选或按 SPACE 跳过│
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ 步骤2：可选裁切                      │
├─────────────────────────────────────┤
│ • 鼠标移动显示竖线                   │
│ • 左键点击确认裁切（保留右侧）       │
│ • SPACE 键跳过裁切                   │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ 步骤3：选择植株颜色参考              │
├─────────────────────────────────────┤
│ • 在背景图上框选一块植株本体颜色     │
│ • 用于后续豆荚/种子的颜色校正        │
│ • SPACE/ENTER 确认，S 跳过           │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ 步骤4：放置豆荚                      │
├─────────────────────────────────────┤
│ 1) 在豆荚图上框选区域                │
│ 2) SPACE/ENTER 确认                  │
│ 3) 调整位置和大小：                  │
│    - 鼠标移动 → 改变位置             │
│    - 滚轮 → 缩放大小                 │
│    - 左键点击 → 确认放置             │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ 步骤5：放置种子                      │
├─────────────────────────────────────┤
│ 操作与豆荚相同                       │
└─────────────────────────────────────┘


【快捷键说明】
通用快捷键（所有窗口）：
  SPACE/ENTER  → 确认当前步骤
  ESC          → 退出/取消当前窗口
  R            → 重做当前步骤
  S            → 跳过当前步骤
  右键         → 撤销上一个框选

框选操作：
  拖拽鼠标     → 画矩形框
  左键点击     → 确认放置（仅放置阶段）
  鼠标滚轮     → 缩放（仅放置阶段）


【输出结果】
处理完成后，结果会自动保存到：
  outputs/
  ├─ bg_cleaned/   # 清理后的背景图
  │  └─ 0001_bg_cleaned.jpg
  └─ final/        # 最终合成图
     └─ 0001_final.jpg


【常见问题】

Q: 程序闪退怎么办？
A: 1. 确保 images/bg、images/pod、images/seed 三个文件夹都存在
   2. 确保图片文件名中包含4位数字编号
   3. 尝试在命令行中运行查看错误信息：
      按 Win+R → 输入 cmd → 拖动 batch_process.exe 到窗口

Q: 如何重新处理已完成的图片？
A: 程序会自动跳过已存在的结果。如需重新处理，
   手动删除 outputs/final/ 中对应的图片即可。

Q: 可以中途退出吗？
A: 可以。已处理完的图片会保存，下次运行时会自动跳过。

Q: 框选错了怎么办？
A: 按 R 键重做当前步骤，或者按右键撤销上一个框选。


【技术支持】
如遇问题，请提供以下信息：
  1. 操作系统版本（Win10/Win11）
  2. 图片数量和编号示例
  3. 报错信息截图或命令行输出
